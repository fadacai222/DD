# 需求完善总览

## 1. 原始目标

构建一套交互习惯接近微信、但品牌和素材原创的开源自托管 IM 系统，支持：

- 邮箱注册、登录。
- 查找和添加好友。
- 文字聊天。
- 语音消息。
- 语音通话。
- 视频通话。
- 朋友圈。
- 扫码。
- Web、PC、Android、iOS 多端。
- 任何拥有公网服务器的用户均可自行搭建。

## 2. 完善后的产品范围

### 2.1 账号与身份

- 邮箱注册、邮箱验证码、密码登录。
- 唯一用户 ID、可修改昵称、不可频繁修改的账号短号/用户名。
- 头像、个性签名、地区、二维码名片。
- 找回密码、修改邮箱、注销账号、导出个人数据。
- 多设备登录、设备列表、远程退出、异常登录提醒。
- 可选 TOTP 双因素认证和 WebAuthn/Passkey。
- 实例管理员可配置：公开注册、邀请注册、管理员审核注册、关闭注册。

### 2.2 好友与关系链

- 按账号短号搜索。
- 是否允许按邮箱搜索由用户隐私设置决定，默认关闭。
- 扫描个人二维码添加好友。
- 好友申请、验证消息、备注、标签、黑名单、删除好友。
- 陌生人消息开关。
- 防骚扰：申请频率限制、批量搜索限制、封禁和举报。

### 2.3 单聊与群聊

- 单聊、群聊。
- 文字、Emoji、图片、文件、语音条、短视频、链接卡片。
- 回复、引用、转发、撤回、删除本地记录、复制、收藏。
- 消息送达状态、可配置已读回执。
- 消息置顶、会话免打扰、草稿、@提醒、未读数。
- 离线消息、多设备同步、断线重连、历史消息分页。
- 群成员、群主、管理员、群公告、群昵称、群二维码、入群审批。
- 首版不做公众号、小程序、支付、红包、直播。

### 2.4 语音消息

- 按住说话、上滑取消、录音时长提示。
- 波形展示、录制最大时长限制、发送前试听可选。
- 语音转文字作为可选插件，不纳入核心依赖。
- 播放进度、听筒/扬声器切换、倍速播放。
- 服务端只保存音频文件和必要元数据；启用端到端加密时，音频由客户端加密后上传。

### 2.5 语音与视频通话

- 首版优先保证一对一语音和视频通话。
- 呼叫、响铃、接听、拒绝、忙线、超时、挂断。
- 麦克风、摄像头、扬声器切换。
- 前后摄像头切换、网络质量提示、弱网降级。
- 通话记录只保存必要元数据，不默认录音录像。
- 群语音/群视频作为后续阶段。
- WebRTC 媒体通道使用 LiveKit，自托管 TURN 保证复杂网络连通。

### 2.6 朋友圈

- 发布纯文字、图片、短视频。
- 可见范围：公开给好友、仅部分好友、不给谁看、仅自己。
- 点赞、评论、回复评论、删除自己的内容和评论。
- 屏蔽某人的朋友圈、不看某人、禁止某人看我。
- 时间线分页、媒体预览、内容折叠。
- 内容举报、管理员处置工具由实例部署者掌控。
- 首版朋友圈不是端到端加密区域；明确向用户展示其隐私模型。

### 2.7 扫码系统

首版二维码仅用于：

- 个人名片。
- 添加好友。
- 群邀请。
- Web/PC 扫码登录。
- 客户端内深链跳转。

明确不包含：

- 支付二维码。
- 收款码。
- 扫码打开任意外部脚本或高权限动作。

扫码登录必须具备：短时效、一次性 token、设备信息展示、手机二次确认、确认后立即失效。

### 2.8 通知系统

- Web：浏览器通知 + Service Worker。
- Android：优先 FCM；可选 UnifiedPush；前台使用 WebSocket。
- iOS：APNs。此能力无法完全自托管，部署者必须自行配置 Apple 凭据。
- PC：系统通知。
- 通知内容支持隐私模式，只显示“你有一条新消息”。

### 2.9 管理后台

- 实例基础配置、品牌、域名、SMTP、存储、推送、LiveKit/TURN。
- 用户列表、封禁、解封、注销、角色管理。
- 注册策略、邀请系统、风控阈值。
- 举报处理、违规内容定位、审计日志。
- 系统健康、在线人数、消息吞吐、队列积压、对象存储容量。
- 数据备份、恢复、迁移和版本升级状态。
- 管理员不能通过普通后台直接查看启用端到端加密的消息正文。

## 3. 非功能需求

### 3.1 隐私

- 数据最小化。
- 不要求手机号和通讯录上传。
- 通讯录匹配功能如后续加入，必须默认关闭并使用隐私保护方案。
- 提供账号删除、数据导出、会话清理、媒体过期策略。
- 服务端日志不得记录密码、验证码、令牌、消息明文、完整邮件内容。

### 3.2 安全

- 全站 HTTPS/WSS。
- 密码使用 Argon2id。
- 登录、注册、验证码、搜索、好友申请、消息发送、上传全部限流。
- 所有上传文件进行类型、大小、扩展名、魔数和病毒扫描校验。
- 服务端与客户端输入均进行结构化验证。
- 端到端加密不得自行设计算法。
- 管理操作写入不可抵赖审计日志。

### 3.3 性能目标

以下是首版目标，不是无限扩展承诺：

- 单实例小型部署：1000 注册用户、200 同时在线、每秒 100 条消息可稳定运行。
- 常规文本消息从服务端接收到推送给在线用户的 P95 小于 300ms。
- WebSocket 断线后 5 秒内开始自动重连。
- 客户端重新上线后能够增量补齐缺失事件，不要求全量拉取。
- 图片和视频不经过应用进程整块转发，采用对象存储直传或受控代理。

### 3.4 可维护性

- 模块化单体，模块之间通过明确接口通信。
- OpenAPI 作为 REST 合同。
- 数据库迁移可回滚或提供明确补救脚本。
- Docker 镜像支持 amd64 和 arm64。
- 配置全部通过环境变量和配置文件，不把秘密写入仓库。
- 每次发布包含升级说明、数据库迁移说明和回滚说明。

## 4. 分期范围

### MVP

- 邮箱注册登录。
- 用户资料。
- 查找、添加、删除、拉黑好友。
- 单聊文字消息。
- 图片和文件消息。
- WebSocket 在线推送、离线同步。
- Web + Android + Windows 基础客户端。
- Docker Compose 部署。
- 管理后台最小功能。

### Beta

- 群聊。
- 语音条。
- 一对一语音/视频通话。
- 朋友圈。
- 二维码名片、加好友、群邀请、扫码登录。
- iOS 和 macOS 客户端。
- 消息搜索、数据导出、备份恢复。

### 1.0

- 私聊端到端加密达到可发布标准。
- 多设备密钥与设备验证。
- 通话端到端加密。
- 安全审计、压力测试、灾难恢复演练。
- 完整安装器、升级器、运维文档。
- 开源许可证、贡献指南、行为准则、漏洞披露流程。

### 2.x 候选

- 群聊端到端加密。
- 群语音和群视频。
- 插件系统。
- 机器人 API。
- 跨实例联邦。
- 可选匿名身份或去中心化身份。

## 5. 明确不做

- 不做支付、转账、红包、金融账户。
- 不做公众号和广告平台。
- 不做内容推荐算法。
- 不做通讯录强制上传。
- 不承诺规避任何国家或地区法律。
- 不以“反审查”为理由取消部署者的反垃圾、封禁和举报能力。
- 不自行实现加密算法、WebRTC 媒体服务器或邮件服务器。
