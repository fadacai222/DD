# 1. 当前版本判断

DD 已经跨过“基础聊天 Demo”阶段，当前属于 **大功能快速扩展后的 Alpha/Beta 收敛期**。

已经有正式业务主链：

```text
P0  Realtime foundation
P2  Auth / User / Device
P3  Contacts / Relationship / Block
P4  Messaging / Outbox / Cursor Sync
P5  Media / Voice / Video / Sticker / productivity
P6  Groups
P7  Formal 1:1 Calls
P8  Moments
P9  QR server + Flutter implementation（定向自动证据已恢复，真人待验收）
P10 Push（主体已实现，真实 Android Push 待设备权限验收）
```

尚不能称 Stable 1.0，因为：

- **当前 Flutter 全局自动门禁已恢复**：2026-08-12 本轮 ASCII 短路径 `dart analyze --fatal-infos` 为 0 issue，Flutter 全量测试 361 PASS / 5 SKIP（真实视频样本环境变量未提供），服务端 `go test ./...` PASS；当前发布阻断已转为真人多端/真机/生产发布链验收债务；
- P9 QR 的定向 analyzer/tests/build 历史证据已恢复，但真人扫码/相机/跨设备登录仍未验收；
- P10 服务端/客户端 Push 主体已完成，但“App 被杀后台仍能收到真实 FCM”的设备级真人验收尚未通过；
- P11 E2EE 已明确退出 V1，不再作为发布阻塞项；
- P12 Admin/Abuse/Data Rights 未实现；
- P13 生产自托管、备份恢复、升级回滚、可观测性未形成完整发布证据；
- P14 iOS/macOS 未正式交付；
- P6/P7/P8 仍有真人多端、弱网和规模验收债务；
- R15 历史 UI/通知/Windows/Android 修复仍有部分 `FIXED-PENDING-RETEST`。

# 2. 状态词

```text
IMPLEMENTED
AUTO-VERIFIED
HUMAN-PASS
FIXED-PENDING-RETEST
KNOWN-FAILURE
IN-PROGRESS
PLANNED
```

规则：

- `IMPLEMENTED` 只说明代码存在；
- `AUTO-VERIFIED` 必须对应当前可重复自动证据；
- 当前门禁重新失败时，旧 `AUTO-VERIFIED` 必须撤销/降级；
- 目标平台没真人复测不能写 `HUMAN-PASS`。
