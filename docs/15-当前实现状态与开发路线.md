# 1. 当前版本判断

DD 已经跨过“基础聊天 Demo”阶段，当前属于 **大功能快速扩展后的 Alpha/Beta 收敛期**。

已经有正式业务主链：

```text

P2  Auth / User / Device

P4  Messaging / Outbox / Cursor Sync
P5  Media / Voice / Video / Sticker / productivity
```

尚不能称 Stable 1.0，因为：

- P9 Flutter 自动门禁已恢复，但真人扫码/相机/跨设备登录仍未验收；

- P12 Admin/Abuse/Data Rights 未实现；

- R15 历史 UI/通知/Windows/Android 修复仍有部分 `FIXED-PENDING-RETEST`。

# 2. 状态词

```text
IMPLEMENTED
AUTO-VERIFIED
HUMAN-PASS
FIXED-PENDING-RETEST
KNOWN-FAILURE
IN-PROGRESS
PLANNED
```

规则：

- `IMPLEMENTED` 只说明代码存在；
- `AUTO-VERIFIED` 必须对应当前可重复自动证据；
- 当前门禁重新失败时，旧 `AUTO-VERIFIED` 必须撤销/降级；
- 目标平台没真人复测不能写 `HUMAN-PASS`。
