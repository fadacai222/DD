## 4. 邮箱验证码

当前实现：

- 6 位随机数字。
- 默认 10 分钟有效。
- 同邮箱 60 秒发送冷却。
- 15 分钟最多 5 次发送。
- 最大校验尝试次数。
- 数据库只存 HMAC 哈希，不存验证码明文。
- 来源 IP 只保存哈希化元数据。
- 已注册邮箱请求注册验证码仍返回 accepted，减少账号枚举。
- SMTP 失败会使本轮验证码失效。
- 开发环境使用 Mailpit 真 SMTP 联调。

开发 Mailpit：

```text
SMTP: 127.0.0.1:11025
Web:  http://127.0.0.1:18025
```

## 5. 注册与密码

注册事务原子创建：

```text
验证码消费
+ users
+ user_privacy_settings
+ auth_passwords
+ 首设备 devices
+ 首个 refresh token family
```

密码：

```text
Argon2id
```

支持：

- 随机 Salt。
- 参数写入哈希编码。
- 正确 / 错误密码验证。
- `NeedsRehash`。
- 参数升级后登录时重哈希。
- 未知账号执行 dummy Argon2，降低明显时序枚举。

禁止：

- 明文密码入库。
- 明文密码日志。
- 对客户端返回密码哈希。

## 6. 登录安全

对外统一：

```text
未知邮箱
错误密码
→ INVALID_CREDENTIALS
```

不会分别告诉客户端“账号不存在”或“密码错了”。

当前已增加：

```text
15 分钟累计 10 次登录失败后限流
Auth 安全审计事件
```

登录成功会建立新的设备和 Token Family。

## 7. Access Token

当前：

```text
算法：HS256
默认有效期：15 分钟
Audience：dd-api
Issuer：dd
```

Claims：

```text
sub = user id
device id
jti
iat
nbf
exp
```

服务端不是只验证 JWT 签名：每次正式 Access 鉴权还会检查对应用户和设备是否仍然有效。

因此设备被远程撤销后，即使旧 Access Token 还没自然过期，下一次 API 请求也会被拒绝。

## 8. Refresh Token

Refresh Token：

- 32 字节密码学随机值。
- Base64URL。
- 数据库仅保存 SHA-256 哈希。
- 默认 30 天。
- 每次使用都轮换。
- `family_id` 表示一次登录族。
- `parent_token_id` 记录轮换关系。

### 重放处理

```text
R1 登录产生
→ 使用 R1
→ R1 标记 used
→ 产生 R2
→ 再次重放 R1
→ 检测 reuse
→ 整个 family revoked
→ R2 也不可继续用
```

真实 PostgreSQL 集成已验证。

## 9. 密码找回 / 重置

流程：

```text
请求重置验证码
→ Mailpit / SMTP 发信
→ 校验验证码
→ 设置新 Argon2id 密码
→ 撤销所有旧设备 / Refresh Token
```

真实集成测试已经验证：

```text
旧密码失败
旧会话失效
新密码成功
```

这样密码被找回后，不会让攻击者拿着之前登录的设备无限续期。

## 11. 设备管理

支持：

```text
GET    /api/v1/devices
DELETE /api/v1/devices/{deviceId}
POST   /api/v1/auth/logout-all
```

能力：

- 查看自己的设备。
- 标识当前设备。
- 远程撤销指定设备。

- 全部退出。
- 被撤销设备的 Access Token 下一次请求立即失效。

## 12. Native 与 Web 会话边界

### Native：Windows / Android / iOS / macOS / Linux

Refresh Token 进入：

```text
flutter_secure_storage
```

App 启动时：

```text
读取安全存储
→ 尝试 Refresh
→ 成功恢复会话
→ 失败清理失效本地状态
```

Native “退出本机”会真正调用服务端撤销当前设备，而不是只清理 Flutter 内存。

### Web

Web **永远不把 Refresh Token 暴露给 Dart/JS**。

Cookie：

```text
dd_refresh
HttpOnly
SameSite=Lax
Path=/api/v1/auth
Secure（HTTPS）
```

Flutter Web：

```text
BrowserClient.withCredentials = true
```

页面启动可通过 Cookie 走 Refresh 恢复会话。

## 15. Windows clean Release 当前环境阻塞

当前机器上的 Windows clean Release 已经排除旧 CMake `O:` 路径缓存问题。

现在唯一明确构建阻塞是：

```text
flutter_secure_storage_windows
→ 需要 ATL
→ 缺 atlstr.h
```

需要 Visual Studio Build Tools 组件：

```text
Microsoft.VisualStudio.Component.VC.ATL
```

项目 `scripts/build-client.ps1` 已增加 ATL 预检；缺少时会立即失败并打印管理员安装命令。

这个是本机 VS 构建环境缺依赖，不是 Auth / P3 业务代码编译错误。
