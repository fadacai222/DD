# ADR-006：采用微信式交互，但不复制品牌资产

## 状态

Proposed

## 日期

2026-08-07

## 背景

用户希望 UI 照着微信，以降低学习成本。但像素级复制、使用相同名称、图标、提示音、文案和素材会带来版权、商标、不正当竞争和应用商店审核风险。

## 决策

- 参考微信的信息架构、操作习惯和聊天产品心智。
- 使用原创项目名、Logo、应用图标、颜色 Token、组件样式、插画、提示音和文案。
- 不从微信安装包提取任何资源。
- 不在仓库中放置腾讯、微信、WeChat 商标或素材。
- Design System 支持实例品牌定制。
- 发布前进行商标检索和 UI 法务审查。

## 可参考的交互

- 移动端底部主导航。
- 会话列表、联系人、发现和个人中心的信息分区。
- 聊天气泡、按住说话、扫码登录等通用交互模式。

## 禁止复制

- 微信名称和近似混淆名称。
- 官方绿色、图标和 Logo 的组合识别系统。
- 原版表情、插画、声音、启动页和专有文案。
- 像素级页面复刻和对外宣传“微信破解版/替代官方微信”。

## 后果

- 需要先建立原创品牌和 Design Token。
- 截图可让用户觉得熟悉，但不能让普通用户误认成腾讯官方产品。
- 多实例可换品牌，但必须保留开源许可证和必要声明。
