## 说明

本文件是早期同编号 ADR 的旧命名副本。为保留历史路径而不直接删除，但 **不得继续作为开发决策来源**。

当前有效决策仍是：

- DD 不自行设计 E2EE 密码协议。
- `crypto/e2ee_poc` 的 `vodozemac 0.10.0` 只是候选技术 PoC。
- 正式 E2EE 尚未接入主客户端/主服务端。
- 最终生产库、FFI/WASM、多设备、附件加密和安全评审仍需后续正式方案。
