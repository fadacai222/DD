# 2. 消息生产力能力

## 2.1 转发

状态：`IMPLEMENTED`

当前：

```text
POST /api/v1/messages/{messageId}/forward
messages.forwarded_from_message_id
```

客户端消息菜单已有“转发”。

要求继续保持：

- 权限服务端检查。
- 新消息拥有自己的 conversation/sequence/clientMessageId。
- 源消息不存在/不可访问时不可绕过。

# 16. Telegram Sticker Pack

状态：`FIXED-PENDING-RETEST`

架构已经从“客户端直连 Telegram 文件”收口为：

```text
link → setName
→ DD server Telegram Bot API
→ provider bytes
→ DD private storage
→ stable DD mediaId
```

当前只稳定承诺静态 WebP。

TGS/WebM 记 unsupported，不假成功。

安全：

- 不接 arbitrary URL。
- Bot Token 服务端 secret。
- 用户订阅权限独立。

# 22. Windows 原生窗口

状态：`FIXED-PENDING-RETEST`

历史真人发现：

- 四边四角 resize 全失败。
- 标题栏按钮异常。
- Windows 11 圆角异常。
- DPI 灰块/色块。

当前 native runner 增加：

- Flutter child HWND subclass。
- `WM_NCHITTEST` parent resize border。
- DPI-aware border/min size。
- `WM_ERASEBKGND` suppression。
- 单实例。

必须真人 100/125/150% DPI 重测。
