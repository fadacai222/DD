> 2026-08-10 04:11 人工测试曾在这里触发阻断：`Unexpected end of input`。已定位并根修，**请从本项重新测试，不需要清 App 数据或重建账号**。
> 
> 根因：客户端用 `9999-12-31T23:59:59Z` 表示“永久免打扰”；PostgreSQL/pgx 按本机 `+08:00` 扫描后变成公元 `10000-01-01 07:59:59 +0800`，Go `time.Time.MarshalJSON` 无法编码公元 10000 年。旧 HTTP `writeJSON()` 又吞掉编码错误，最终服务端错误地返回 `HTTP 200 + 0 字节正文`，客户端对空字符串执行 `jsonDecode()` 才显示 `Unexpected end of input`。
> 
> 已修：服务端 Conversation 时间出库后统一转 UTC；JSON 编码失败不再静默返回 200 空正文，而是结构化 500；新客户端永久免打扰改用安全的 9998 年上限；客户端若未来再遇空响应会提示“消息服务返回了空响应”，不再暴露底层 JSON 异常。真实 PostgreSQL 回归与全量门禁均 PASS。修复服务端上线后，**未清数据库、未清手机数据**直接重启旧 APK，`GET /api/v1/conversations` 已由 `200 / 0 bytes` 恢复为 `200 / 3623 bytes`，且 Android 日志没有再新增该错误。
