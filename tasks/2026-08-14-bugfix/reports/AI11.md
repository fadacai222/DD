# AI11：注册验证码 60 秒倒计时与成功提示修复报告

## 状态

`FIXED-PENDING-RETEST`

## 根因

注册页 `auth-send-code` 只受全局 `_busy` 控制；发送验证码 API 成功后没有独立 resend cooldown 状态，也没有 Timer，因此请求结束后按钮立刻恢复可点。成功提示仍是开发期 Mailpit 文案，与当前产品文案不一致。

服务端已有正式 60 秒发送 cooldown，本次未修改服务端限流、验证码 TTL、burst/window 策略。

## Timer 状态设计

- 新增 `_registrationCodeCooldownTimer` 和 `_registrationCodeCooldownSeconds`，与全局 `_busy` 分离。
- 只有 `sendRegistrationCode` 成功返回后才启动 60 秒倒计时。
- 倒计时期间 `auth-send-code` 的 `onPressed == null`，使用 Flutter 原生 disabled/灰色按钮视觉，并显示 `N 秒后重试`。
- 每秒递减一次，归零后自动恢复“发送验证码”和点击能力。
- 启动新 cooldown 前会取消旧 Timer，避免重复实例。
- 页面 `dispose()` 时取消 Timer；回调也检查 `mounted`，避免 `setState after dispose`。
- 登录/注册 Tab 切换只重建表单显示，不重新创建 Timer，因此不会叠加倒计时。
- 请求失败不会调用 cooldown 启动逻辑。
