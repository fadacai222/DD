## 任务 1：B09 首页左右滑“连键”

用户要求严格语义：

> 左滑呼出 → 右滑只负责取消；取消以后，再右滑才可以呼出另一侧；随后左滑只负责取消。

也就是**一次反向手势不能从 A 侧直接穿越到 B 侧**。

当前 `_ConversationSwipeActionsState` 只有 `_offset`，drag update 直接：

`_offset = (_offset + delta.dx).clamp(-leftReveal, rightReveal)`

因此没有“已打开哪一侧”的离散状态。

### 必须实现

建立明确状态机，名称自定，例如：

- closed
- leadingOpen
- trailingOpen

规则：

1. closed + 左滑达到阈值 => 一侧 open。
2. 该侧 open 后，右滑这一整次 gesture 最多只能回 closed，**不可同一 gesture 继续打开另一侧**。
3. gesture end 后已经 closed，下一次新的右滑才可打开另一侧。
4. 对称方向完全一致。
5. action tap 成功/失败处理完成后回 closed。
6. busy 时不能拖出半开状态。
7. drag cancel 回到合理的原状态，不出现跳边。
8. 保留现有操作：置顶/已读、静音/归档/删除。

### 必须测试完整序列

至少：

`closed -> left-open -> opposite swipe -> closed -> new opposite swipe -> right-open -> opposite swipe -> closed`

以及反向起始序列。

不能只测单次左滑、单次右滑。
